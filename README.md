# 🏆 GDG Hack Frontend

> **🥇 1st Place Winner — GDG Hackathon**

> **Learn Frontend Development. Play the Game. Defeat the Bosses.**

**GDG Hack Frontend** is a gamified learning platform designed to make learning frontend development more interactive, practical, and engaging.

Instead of following traditional tutorials, learners progress through a **game-inspired learning journey** where lessons become stages, challenges become battles, and milestones unlock new content and bosses.

The platform combines **education, gamification, progression, and multiplayer interaction** into one experience.

## 🌟 Why GDG Hack Frontend?

Learning frontend development can feel repetitive when it is limited to videos, documentation, and exercises.

GDG Hack Frontend introduces a different approach:

**Learn → Practice → Progress → Unlock → Challenge → Master**

The goal is to transform the learning process from a passive experience into an **interactive game-like journey**.

## 🏗️ Architecture

The frontend follows a modular and scalable architecture designed to separate UI, business logic, and API communication.

```text
frontend/
│
├── app/                    # Next.js App Router
├── components/             # Reusable React components
├── hooks/                  # Custom hooks
├── lib/                    # Utilities and shared logic
├── public/                 # Static assets
├── styles/                 # Global styles
│
├── .gitignore
├── package.json
├── tsconfig.json
├── next.config.ts
└── README.md
```

## ⚡ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/oussamatght/GDG-HACK-FRONTEND.git
```

### 2. Navigate to the project

```bash
cd GDG-HACK-FRONTEND
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
